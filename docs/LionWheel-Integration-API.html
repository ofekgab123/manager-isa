API ליצירת משימות LionWheel

ISA Express — מסמך אינטגרציה למפתחים

Endpoint

POST https://os.isa-express.com/api/integrations/lionwheel/create

Authentication

יש לשלוח Bearer token ב-header:

Authorization: Bearer d66d90d47eb26fe9b8847bd0cc9c92974158e8086d03a9cf854c5b3a165997a6
Content-Type: application/json

שדות הבקשה

שדהחובה / אופציונליתיאור
destinationחובהindia או thailand — קובע לאיזה חשבון LW נשלח
cityחובהעיר
nameחובהשם הנמען
phoneחובהטלפון
numberחובהמספר בית
orderIdאופציונלימזהה הזמנה אצלכם; אם לא נשלח — נוצר אוטומטית INT-{timestamp}
typeאופציונליpickup או empty
streetאופציונלירחוב; אם לא נשלח — LW מקבל —
boxesאופציונליכמות ארגזים
emptyBoxesאופציונליארגזים ריקים (לאיסוף)

שגיאות אפשריות

  • 401 — token שגוי או חסר
  • 400 — שדות חובה חסרים
  • 502 — שגיאה מ-LionWheel
  • 503 — הגדרות שרת חסרות
